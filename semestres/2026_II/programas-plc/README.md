# Programas PLC (II-2026)

Programas del PLC S7-200 (CPU 224) del brazo: proyectos de STEP 7-Micro/WIN (`.mwp`), exportaciones AWL (`.awl`) y librerías (`.mwl`).

- Un archivo por versión, con el número en el nombre: `brazo_secuencia_v1.mwp`, `brazo_secuencia_v2.mwp`.
- Si el programa es de un eje o de la garra, ponerlo en el nombre: `eje_z_referencia.awl`, `garra_prueba.awl`.
- Exportar también el AWL (en Micro/WIN: *Archivo → Exportar*) para que el código se pueda leer en la página.
