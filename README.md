Brazo de 4 grados de libertad

Proyecto integrador orientado al estudio, documentación, modelado y control de una planta correspondiente a un brazo de 4 grados de libertad.

La planta es controlada mediante un PLC Siemens S7-200 y una botonera de operación. El sistema cuenta con sensores de fin de carrera para la supervisión de las posiciones de los mecanismos.

El brazo permite realizar cuatro movimientos principales:

Movimiento horizontal en el eje X.
Movimiento vertical en el eje Y.
Movimiento rotacional en el eje Z.
Movimiento de agarre mediante una pinza.

El proyecto integra el análisis de la planta, identificación de sus componentes, desarrollo del sistema de control, programación, gestión de información, documentación técnica y realización de pruebas, como un trabajo conjunto entre las asignaturas ETN-902, ETN-1000 y ETN-1040.
